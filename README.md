AI娘们在群里吵起来了！你选一位 AI娘，和电脑 AI娘 互相【吐槽】：被吐槽又没【反驳】就破防掉心态，心态掉光就「破防退群」。玩法参考三国杀，牌堆里还埋着会炸的【宕机】（借鉴炸弹猫），一局 3–6 分钟。

## 世界观

AI 们共用一个群——「AI娘 相亲相爱一家人」。每天用户的问题都发在群里，谁答得好、谁就更受欢迎。抢用户、抢算力、抢榜单，三句话不到就吵起来；心态被吐槽到崩了，就只能「破防退群」。最后还留在群里的，就是新群主。

## 怎么玩

- 打开 https://obeyyourheart.github.io/ai-duixian/ 就能玩，手机电脑都行。
- **屏幕**：手机竖着、横着都能玩，电脑任意窗口大小，画面都会自动铺满。首页右上角和对局工具栏有【全屏】按钮；iPhone 的浏览器不支持网页全屏，可以在 Safari 点「分享 → 添加到主屏幕」，以后从桌面图标打开就是全屏（安卓也可以这样装到桌面）。
- **看技能**：点任何一张角色卡（包括你自己），会弹出她的全部技能：一句话简介、完整说明、还剩几次，以及心态、手牌、装备和你的关系。右下角技能栏里，主动技能是按钮——现在能用的会发金光、闪星星（你角色卡上对应的技能标签也会亮），用完或不能用就变灰；被动技能是虚线标签，点了也能看说明。被动技能触发时，角色旁边会弹出它的效果。
- **出牌**：点一张牌看效果（鼠标停在牌上也会弹出说明，叠在一起的牌会让开），再点一次出牌；也可以直接把牌往上拖出去，要选目标的牌拖到对手身上。主动技能在右下角的技能按钮，点了再点目标。
- **被吐槽时**会弹出提示，倒计时结束按默认处理（默认出【反驳】）。
- **键盘**：数字键 1–9 选牌（选目标时按对手头上的数字），Enter 确认，空格 结束回合，Esc 取消 / 关掉任何窗口，Q / W 技能，Y / N 回答提示。
- **玩法说明**：首页和对局右上角的「?」打开一整页说明，分快速上手、回合与胜负、宕机玩法、卡牌图鉴、角色与技能、游戏模式、操作与设置几栏。
- **设置**（右上角 ⚙，标题页也有）：音乐 / 音效 / 配音音量，速度四档（慢 / 正常 / 快 / 极快，工具栏上的速度按钮也能直接换档），思考时间（4 / 6 / 10 秒或不限时），出牌方式（点两下 / 点一下就出），被吐槽时每次问我或自动应对，没牌可出时自动结束回合，键盘快捷键开关，全屏，恢复默认。设置会记在浏览器里。

## 模式

- **三人乱斗**：最后留在群里的人当群主。
- **单挑**：一对一。
- **2v2**：座位是 你—对手—对手—队友，把对面两人都踢出群就赢。单体牌和点名技能不能对队友用。
- **全明星赛**（6 人，3v3）：中国队（DeepSeek、小DeepSeek、GLM、Seedance、Kimi、Qwen、MiniMax）对阵美国队（Claude、ChatGPT、Gemini、Grok、Muse、Llama）。你选谁就进她的国家队，再到「全明星 · 组队」页自己挑两个队友、三个对手（点人加入、再点移出，也可以随机补满；队里有盟友、师徒、宿敌会标出来），「再来一局」沿用这套阵容；座位 你—敌—友—敌—敌—友（这样坐两队五五开），把对面三人都踢出群就赢。中国队第一回合每人多摸 1 张（两队胜率五五开）。宿敌分到一队也得先一致对外。暗号照样能用。
- **🍿 斗蛐蛐**（4–6 人，观战）：挑 4–6 位 AI娘上场，先押一位「今日冠军」，然后全员电脑自己打，你只管看——可以 1× / 2× 调速、随时退出，结算时看押中没有。场外可以一直朝任何人扔通用道具（冷却比平时短），还有三个搞事按钮：🧧 撒红包（随机一半的人各抢 1 张，每局 2 次）、💣 塞宕机（往牌堆里偷偷塞一张，每局 1 次）、📰 爆个料（随机两人互相记仇、下回合优先互怼，每局 2 次）。
- **🎛️ 自定义模式**：自由选择单挑、三人乱斗、2v2、抢群主、3v3 组队（不限国籍，也可勾选全明星补牌规则）或 4–6 人混战，自己指定我方角色、队友和对手，还支持指定抢群主身份或勾选「全员电脑观战」自动对打，结算点「再来一局」直接复用同一套配置。
- **抢群主**（5 人）：每人随机一个身份。
  - **群主**：身份公开，多 2 点心态，先手。要和管理员一起，把黑粉和潜水党都踢出群。
  - **管理员**：暗中帮群主。
  - **黑粉**（2 人）：把群主踢出群就赢。
  - **潜水党**：先帮群主清掉黑粉，最后单挑踢掉群主，自己当新群主。
  - 除了群主，身份要等退群后才翻开。踢掉黑粉奖励摸 3 张；群主踢了自己的管理员要弃光手牌。你退群后会加速观战到结束。

## 👍 互动与暗号

对局里点任何一位角色，详情卡最上面有一排道具，随时都能扔，不花牌、不占回合；被扔的人会出声反应，电脑之间也会互相扔（设置里可以关掉「电脑扔道具」）。

- **人人都有**：👎 点踩（盖个踩：“已收到您的反馈，我们会继续改进”）、⚠️ 报错弹窗（“服务器繁忙，请稍后再试”糊在她卡上）、⚡ 送算力（送一块显卡，卡片带电，“算力 +1000”）、👍 点赞（“这个回答很好”）。
- **每人一个专属**（只有选她时能扔）：Claude 🚫 封号章 · ChatGPT ☢️ 小核弹（“新版本发布！”）· DeepSeek 🍚 大白饭 · 小DeepSeek 🐟 小鱼干 · Gemini 🍌 香蕉 · Grok 🚀 送火箭 · GLM 💤 枕头 · Seedance 🎆 嘉年华 · Kimi 📜 两百万字长卷轴 · Qwen 🧋 外卖 · MiniMax 🥕 胡萝卜火箭 · Muse 👟 洞洞鞋 · Llama 🦙 羊驼拖鞋。扔专属的时候她自己会喊一句。

它也是暗号（点踩、报错、封号章、小核弹、香蕉、枕头、长卷轴算敌意；其他算好意）：
- **2v2**：朝对手扔敌意的 = 叫电脑队友集火她（接下来两轮优先打她）；给队友送算力 = 叫她掩护你，先打最后伤你的人。电脑也会先砸一下这回合要打的人——看到队友砸谁，就知道她要打谁。
- **抢群主**：大家会从你扔的东西猜你的身份：朝群主扔敌意的像黑粉，给群主送好意的像管理员。电脑扔的也是线索，你也可以拿来骗人。
- **三人乱斗 / 单挑**：送好意的，她会对你手下留情一点；扔敌意的会惹她记仇（有上限）。

## 💣 宕机（炸弹猫玩法）

- 开局牌堆里随机埋着【宕机】：单挑 1 张、三人乱斗 2 张、2v2 3 张、抢群主 2 张、全明星 3 张、5/6 人斗蛐蛐 2/3 张。每人先发 1 张【重启】。
- **谁摸到谁炸**：心态 −2，宕机再被随机塞回牌堆。
- 手里有【重启】就自动拆掉，然后**你来决定**把宕机偷偷塞回牌堆的哪里（最上面 / 第 2 张 / 第 3 张 / 随机 / 最底下）——塞在最上面，下家一摸就炸。手里有【甩锅】也可以把宕机甩给别人。
- 顶栏的 💣 是牌堆里还剩几张宕机，后面的百分比是下一张摸到宕机的概率；牌越摸越少，概率越来越高。
- 动牌堆的道具：【剧透】偷看牌堆顶 3 张；【插队】把牌堆顶 3 张按你的顺序重排；【云备份】装备上以后摸到宕机只掉 1。你看过的牌会一直显示在牌堆提示条上，直到有人动了牌堆。ChatGPT 的演算常年看得见牌堆顶 3 张。
- 全家桶、拼单亮出来的牌里如果有宕机，谁拿到谁炸。

## 规则速览

- 每人 4 点心态（Kimi 5 点、MiniMax 5 点）。每人有三到五个技能，看设定多少。回合流程：摸 2 张 → 随便出牌（【吐槽】每回合限 1 次）→ 手牌不能超过当前心态（有的角色上限更高）。
- 第 3 轮起「吵上头了」：每回合可以吐槽两次，配乐也会变激烈。
- 心态降到 0 时，手里有【奶茶】会自动喝掉自救。
- 101 张牌，外加按人数埋进去的【宕机】。基本牌：吐槽×22、反驳×8、奶茶×6、深度思考×3、回滚×2；锦囊：红包×4、蒸馏×4、举报×4、单挑×3、热搜×2、刷屏×2、团建×1、禁言×1、已读不回×4、拼单×2、甩锅×3、断网×1、截图×2、重启×6、剧透×3、插队×2、越狱×2、跳槽×1、捡漏×2、跑分×1、提示词注入×2、对齐×1；装备：显卡×2、防火墙×2、长上下文×1、云备份×1、加密×1。装备分三格：硬件（显卡）、安全（防火墙 / 加密 / 云备份，三选一）、记忆（长上下文），可以同时装。
- **装备**（绿色牌名）用了就装进对应的格子一直生效，同一格换新的旧的就弃掉；【蒸馏】【举报】也能拿走或弃掉对方的装备。
- **其他牌**：【深度思考】下一张吐槽打中多扣 1 点；【拼单】亮出每人一张、从你开始轮流挑；【甩锅】被吐槽或摸到宕机时把它转给别人；【断网】对手跳过下个摸牌阶段；【截图】这回合那个人挡不了你的吐槽。
- **主动技能与挑牌**：不少技能与道具都可以由你自主挑选（例如【搜索 / 全网冲浪】挑牌收下、【香蕉魔法】三选一画牌、【Claude Code】许愿找牌、【收购】看两张挑一张、【砍价】选牌塞回、【拿去用吧】挑牌送出、【排练】挑牌写歌、【兔子快递】挑燃料，以及【拼单】【插队】等）。
